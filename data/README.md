# Data

`ai4i2020.csv` (AI4I 2020 Predictive Maintenance, UCI: https://doi.org/10.24432/C5HS5C)
is tracked with DVC and stored on DagsHub (https://dagshub.com/long-blip/COS40007-HCM6).
Run `dvc pull` to download it.
`data/processed/` is generated by `src/preprocess.py` and is not tracked.

## New data batches
`data/new/` holds new labelled batches and is tracked with DVC (`data/new.dvc`).
Simulated batches are created by `python src/simulate_batches.py` in `data/simulated/`.

To add a batch (this triggers retraining on push to main):
1. Copy the batch into `data/new/`, e.g. `data/simulated/batch_002.csv`
2. `dvc add data/new` and `dvc push`
3. Commit `data/new.dvc` and push

The pipeline validates every batch (`ingest_batches`), adds new rows to training (`preprocess`),
retrains, monitors the champion on the newest batch, and promotes the candidate only if it wins.
